# Crimson visual system

## Identity
The Crimson mark is an original angular energy crest: a geometric shield, an open silver C, a cyan energy slash, and a compact crown motif. It is designed to remain recognizable at launcher-icon size without relying on a wordmark.

## Interface direction
- **Background:** near-black plum (#0A080E)
- **Panels:** deep charcoal-plum (#16111B)
- **Primary:** electric crimson (#FF3B52)
- **Accent:** cool cyan (#38D9FF)
- **Text:** soft white (#F5F1F6)
- **Secondary text:** muted lavender-grey (#AEA4B4)
- **Success:** green reserved for confirmed healthy/connected states
- **Warnings:** amber reserved for permissions, unsupported operations, and caution states

## UI principles
- Live values are labelled as device telemetry, not predicted FPS gains.
- Destructive or system-level actions remain explicit, permission-gated, and confirmed.
- Cards use consistent 18dp corners, subtle borders, and restrained elevation.
- Primary actions use a crimson gradient; secondary actions use a quiet outlined surface.
- Text and control contrast is checked against WCAG AA targets.
- The interface must remain useful on narrow Android screens and with larger system font settings.

## Product truth
Crimson reports what Android exposes and requests only supported APIs. It does not promise universal FPS unlocking, disable thermal protections, bypass anti-cheat, or claim an operation succeeded before Android reports its result.
